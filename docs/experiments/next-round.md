## 每次接手

1. 阅读本页和最近一次实验报告，检查同一轮的 GitHub Actions。运行中沿用既有 run ID；有新结果时先归档产物，再从文件独立重评。
2. 将原始分数、实际提示词与完成返回的代码、数据与代码提交、失败或缺测原因、汇总表与图写回实验分支。无新结果时保留已有记录。
3. 根据预登记判据写下继续、停止或证据不足。下一轮立项时更新本页，明确唯一变量、比较基线、留出数据和继续条件。
